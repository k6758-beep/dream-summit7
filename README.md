# 夢想攻頂！正修冒險隊

> 蒐集夢想寶物，解鎖你的升學路線，直達未來之門！

高中職應屆畢業生探索正修科技大學升學管道的登山冒險 RPG。四關、約 3 分鐘，最後帶走一張個人化「攻頂攻略卡」。
由《畢業之後 我的夢想之旅》（pursue-dreams5-1）改版：**招生資料、資格判斷規則、推薦排序、時程計算、攻略卡、暫存與續玩連結全部沿用原程式**，只換掉遊戲流程與畫面。

純 HTML／CSS／JavaScript，不需要後端、登入或 API Key；地圖全部用 SVG 繪製，沒有外部圖片。

## 檔案結構

```

data/
```

## 部署到 GitHub Pages

1. 解壓縮後，把資料夾**裡面的所有檔案**上傳到 repository 根目錄（可覆蓋 `pursue-dreams5-1`，或另開新 repo）。`.nojekyll` 是隱藏檔，請一併上傳。
2. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`。
3. 幾分鐘後開啟 `https://k6758-beep.github.io/<repository>/`。
4. 若手機看到的還是舊版，請重新整理或清除快取。

> 舊版的暫存（`grad-journey-v4`）不會被讀取，玩家會從新版開頭開始。

## 遊戲流程（約 3～5 分鐘）

| 關卡 | 玩家要做的事 | 資料來源 |
|---|---|---|
| 開場 | 旁白、挑選角色（6 位）、可填冒險者代號 | `story.js` 的 `opening`、`scene.js` 的 `AVATARS` |
| 第 1 關 🪪 身分關 | 回答學制與應屆題目 → 取得角色徽章，山兩側先亮起「可以走／待確認」的路線 | `admissions.js` 裡 `stage: "create"` 的題目（含 `when`、`set`） |
| 第 2 關 💎 寶物關 | 在校成績、產學專班（單選）；戰績＋特殊經歷（同一個寶箱畫面）；願意準備的事（可跳過，只影響推薦順序） | `stage: "backpack"` 的題目、`willing` |
| 第 3 關 🚡 飛索關 | 看依資格排序的前 4 條路線，點選最多 3 條（主攻／備選／備援），角色以飛索滑到浮島；可「查看其他路線」 | `paths`、`recommend()` |
| 第 4 關 🏔️ 攻頂 | 彈射登頂（金色光尾）、正修之門開啟、攻頂慶祝動畫 → 攻略卡 | — |

* 🚡 飛索路線＝`exam.need: true`（要考試）；🚀 彈射路線＝免考試。
* 「需要進一步確認」（規則 `st: "y"`）一律顯示為待確認，**不會當成不符合**。
* 只答完身分題時，地圖只亮「可以走／待確認」，其他維持「？」，不提前判定不符合。
* 今年已截止（入口日期已過）的路線不能選，攻略卡另外列出。

## 攻頂慶祝動畫

鏡頭推近正修之門 → 門內放出旋轉光束 → 角色舉手歡呼跳三下 → 「🏆 登頂 3952m」緞帶彈出 → 兩波煙火 → 彩帶從天空飄落 → 鏡頭拉回。約 6 秒，全部是背景動畫，「打開我的攻略卡」按鈕一開始就能按。攻頂畫面和攻略卡都有「🎆 再看一次攻頂動畫」。系統設定「減少動態效果」時不播放。

## 學生暨家長聯合說明會提醒

設定在 `data/admissions.js` 的 `contact.parentSession`（標題、說明文字、報名網址、日期、地點）。
出現在：攻略卡（含下載的圖片）、⏰ 時間警報器、📅 加入行事曆（攻頂畫面不顯示）。

* `date` 留空：只顯示提醒和報名連結。
* 填上 `date`（必要時加 `to`、`place`）：顯示倒數，並自動放進手機行事曆與 Google 日曆清單；日期過了之後提醒自動隱藏。
* 目前報名網址先沿用 `https://visit.csu.edu.tw/`，有專屬報名頁時請改 `url`。
* `data-check.html` 會提醒「還沒填日期」或「日期格式錯誤」。

## 加入手機行事曆

時間警報器與攻略卡上的「📅 加入手機行事曆」會打開一個視窗：

* **下載行事曆檔（.ics）**：只放今天以後的時程，每筆提前 3 天提醒；推估的日期在標題標「（推估）」。檔案已依 iCalendar 規範（CRLF、每行 75 bytes 折行）產生，iPhone、電腦（Outlook／Apple 行事曆／Google 日曆匯入）都能讀。
* **＋Google 日曆**：每一筆都有一鍵加入的連結。Android 的 Google 日曆 App 不能直接匯入 .ics，這是 Android 最穩的方式。
* **LINE、FB、IG 內建瀏覽器不能下載檔案**：遊戲會偵測並提示。在 LINE 裡會出現「用手機瀏覽器開啟」，進度會用續玩碼一起帶過去。
* 畫面會依裝置顯示 iPhone／Android／電腦的操作說明。

## 攻略卡內容

身分與徽章、攻頂路線（主攻／備選／備援）、下一步（以真實今天計算）、✅ 依目前資料可考慮的管道（考試需求、原因、主要條件、下一個時間點）、🟡 尚待確認的條件、⛔ 今年已截止、同等學力提醒、📋 我要準備、🗓️ 可拖曳時間軸＋完整時間軸＋加入手機行事曆、🎒 背包工具、QR Code。
按鈕：下載攻略卡圖片、查看完整升學管道圖鑑、前往官方招生資訊、探索正修科系、重新選路線、重新探索。

## 隨時可用的工具

* **↩ 上一步**：回到前一題重新選，資格與路線一起還原。
* **💾 暫存**：每一步自動存在瀏覽器（localStorage 鍵值 `dream-summit-v1`）；可複製續玩連結換裝置接著玩。
* **🗺️ 圖鑑**：完整升學管道圖鑑（道路卡、一年時間軸、每條路完整資訊與正式招生網址），開場就能看。
* **🎒 背包**（8 件全部隨時可用）：升學地圖、科系探索鏡、資格卷軸、⏰ 時間警報器（時間軸＋行事曆）、學長姐的手繪地圖、正修探索鏡、參訪通行證、求助對講機（LINE@、專線電話）。

## 每年更新招生資訊

與原版相同，只改 `data/admissions.js`，改完用瀏覽器打開 `data-check.html` 檢查（紅字一定要修）。詳細欄位說明寫在 `admissions.js` 檔案內。網址有新增或更換時，執行 `pip install segno` 後 `python tools/make_qr.py`。
測試用：網址加上 `?today=2027-03-15` 可以模擬任何一天。
